# 라스트레인 (LastTrain)

심야 환승 귀갓길에서 **"지금 나가면 막차를 탈 수 있는가"** 를 판정하는 프로토타입.

26-2 경영학부 혁신기업경영 캡스톤디자인 II · Team 04

→ **[데모 바로가기](https://rnjswldnjs.github.io/lastrain/)**

## 무엇을 해결하는가

구간별 막차 시각은 이미 지도 앱에 있다. 없는 것은 **구간 사이의 연결 판정**이다.
사용자는 지도 앱과 지하철 앱을 번갈아 보며 도보 이동시간까지 더해 직접 계산하고,
그 계산을 이동 중이나 모임 중처럼 확인이 어려운 상황에서 반복한다.

라스트레인은 그 계산을 대신해 세 가지를 보여준다.

1. 지금 나가면 탈 수 있는가
2. **최종 출발 마감시각** — 기존 앱이 제공하지 않는 숫자
3. 끊기는 구간과 그 원인

## 핵심 로직 — 역산 (backward induction)

도착지에서 거꾸로 올라오며 각 구간을 "늦어도 몇 시에 시작해야 하는가"로 환산한다.
맨 앞까지 오면 그것이 최종 출발 마감시각이다.

어떤 구간의 역산 시각이 그 구간 막차보다 이르면, 뒤쪽 구간이 먼저 끊긴다는 뜻이다.
그 구간을 **병목(끊기는 구간)** 으로 표시하고 원인이 되는 뒤쪽 구간을 함께 보여준다.

규칙 기반이라 결과가 재현되고, 판정 근거를 화면에서 그대로 펼쳐 볼 수 있다.

## 개인 보행 템포

도보 시간에 개인 배율을 적용한다. 10/3 사용자 인터뷰에서 나온 문제다.

> "발목 깁스한 상태인데, 내 이동시간과 지도 앱에 나온 도보 소요 시간이 차이가 많이 나서 막차를 놓쳤다."

배율을 바꾸면 마감시각이 움직이고, 빠듯한 경로에서는 판정 자체가 뒤집힌다.

| 경로 · 구간 소요시간 · 도보시간 | ODsay 대중교통 API 실제 응답 | 확보 |
| 막차 시각 | — | **실측 전 샘플값** |
| 대안(심야버스 · 택시) 소요시간 · 요금 | — | 자리값 |

들어있는 경로 4개는 동작을 보여주기 위한 예시다.
실제로 어떤 귀가 경로가 대표성을 갖는지는 사용자 조사로 정한다.

## 구조

단일 HTML 파일. 빌드 도구 · 프레임워크 · 백엔드 없음.

```
index.html   전체 (스타일 · 판정 로직 · 샘플 데이터)
```

API를 화면에서 실시간 호출하지 않고 수집해 둔 응답을 고정으로 사용한다.
데모 중 네트워크 실패로 판정이 멈추는 것을 막기 위한 선택이다.
