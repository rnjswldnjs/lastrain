# 라스트레인 (LastTrain)

심야 환승 귀갓길에서 **"지금 나가면 막차를 탈 수 있는가"** 를 판정하는 프로토타입.

26-2 경영학부 혁신기업경영 캡스톤디자인 II · Team 04

→ **[데모 바로가기](https://rnjswldnjs.github.io/lastrain/)**

## 무엇을 해결하는가

구간별 막차 시각은 이미 지도 앱에 있다. 없는 것은 **구간 사이의 연결 판정**이다.
사용자는 지도 앱과 지하철 앱을 번갈아 보며 도보 이동시간까지 더해 직접 계산하고,
그 계산을 이동 중이나 모임 중처럼 확인이 어려운 상황에서 반복한다.

라스트레인은 그 계산을 대신해 세 가지를 보여준다.

1. 지금 나가면 탈 수 있는가
2. **최종 출발 마감시각** — 기존 앱이 제공하지 않는 숫자
3. 끊기는 구간과 그 원인

## 핵심 로직 — 역산 (backward induction)

도착지에서 거꾸로 올라오며 각 구간을 "늦어도 몇 시에 시작해야 하는가"로 환산한다.
맨 앞까지 오면 그것이 최종 출발 마감시각이다.

어떤 구간의 역산 시각이 그 구간 막차보다 이르면, 뒤쪽 구간이 먼저 끊긴다는 뜻이다.
그 구간을 **병목(끊기는 구간)** 으로 표시하고 원인이 되는 뒤쪽 구간을 함께 보여준다.

규칙 기반이라 결과가 재현되고, 판정 근거를 화면에서 그대로 펼쳐 볼 수 있다.

## 개인 보행 템포

도보 시간에 개인 배율을 적용한다. 10/3 사용자 인터뷰에서 나온 문제다.

> "발목 깁스한 상태인데, 내 이동시간과 지도 앱에 나온 도보 소요 시간이 차이가 많이 나서 막차를 놓쳤다."

배율을 바꾸면 마감시각이 움직이고, 빠듯한 경로에서는 판정 자체가 뒤집힌다.

## 데이터

| 항목 | 출처 | 상태 |
|---|---|---|
| 경로 11개 · 구간 소요시간 · 도보시간 | 조원 사용자 조사 (지도 앱 실측 캡처) | 확보 |
| 막차 시각 — 평일 | 조원 조사 + 공공데이터 시간표 대조 | 11개 경로 전부 |
| 막차 시각 — 토·일 | 조원 조사 + 공공데이터 시간표 대조 | R10(5511 버스)만 보류 |
| 택시 대안 요금 | 카카오모빌리티 예상 + 심야 할증 40% | 11개 경로 (시계외 할증 제외) |
| 버스 시간표 vs 실제 운행 | 카카오맵 시간표·예측 대조 5건 | 격차 −10~+92분, 보정 안 함 |

원본은 `data/routes.json`.

## 구조

단일 HTML 파일. 빌드 도구 · 프레임워크 · 백엔드 없음.

```
index.html         전체 (스타일 · 판정 로직 · 경로 데이터)
data/routes.json   조원 조사 원본
```

API를 화면에서 실시간 호출하지 않고 수집해 둔 응답을 고정으로 사용한다.
데모 중 네트워크 실패로 판정이 멈추는 것을 막기 위한 선택이다.

### v1.1 — 2026.10.30 (조원 피드백 고유민·방강희 + 나영 디자인 의견 반영)
- 막차 시각 공공데이터 대조: 서울 열린데이터광장 역별 시간표, 국토부 TAGO(김포골드라인·GTX-A·신림선), 서울·경기 버스 노선 API. 조사값과 다르면 더 이른 쪽을 씀
  - 토·일 막차 R07~R11 추가 (토요일 시간표가 없는 노선은 일요일 값). 남은 보류는 R10 토·일(5511 버스)뿐
  - 마감이 바뀐 경로: R07 평일 23:57 → 22:57 (김포골드라인 막차 조사 00:29, 시간표 23:29), R09·R10 평일 보류 → 23:08·23:14
- 기본 테마를 밤하늘 다크로: 남색·보라 그라데이션 + 별 + 하단 도시 스카이라인. 순검정 면 없음. 상단에 밝은 화면 전환 버튼
- 시각을 직접 고르면 "23:10에 출발하면 …", 지금 시계·빨리 감기면 "지금 나가면 …"
- 판정 아래 한 줄 근거 "오늘 마감은 수인분당선 정자역 막차 23:38 기준이에요" + "자세히 보기"로 역산 표
- 구간 줄: "노선 막차 00:27", "탑승 마감까지", 앞 구간이 뒤 막차에 묶이면 "노선 막차 00:27보다 69분 이른 23:18에 타야 다음 구간에 이어져요"
- 도착 예상에 역 이름("강남역 도착 23:07"), 여유 3분 미만이면 "지연되면 놓칠 수 있어요", 막차보다 늦으면 빨간 굵은 글씨
- "출발했어요" → "예상 이동 경로 보기" + "출발 시각과 평균 소요시간으로 추정한 위치예요", 지난 구간은 "도착(예상)·하차(예상)"
- 끊길 때 택시 대안: 카카오모빌리티 예상 요금(23:30) + 심야 할증 40% 추정, 시계외 할증 제외 명시
- 새 기능: 마감 10분 전 알림(화면이 열려 있는 동안), 카카오맵·네이버 지도 길찾기 연결, 귀갓길 공유(공유 시트 또는 복사)
- 홈에 "다시 고르기"
