# 라스트레인 (LastTrain)

심야 환승 귀갓길에서 **"지금 나가면 막차를 탈 수 있는가"** 를 판정하는 프로토타입.

26-2 경영학부 혁신기업경영 캡스톤디자인 II · Team 04

→ **[데모 바로가기](https://rnjswldnjs.github.io/lastrain/)**

## 무엇을 해결하는가

구간별 막차 시각은 이미 지도 앱에 있다. 없는 것은 **구간 사이의 연결 판정**이다.
사용자는 지도 앱과 지하철 앱을 번갈아 보며 도보 이동시간까지 더해 직접 계산하고,
그 계산을 이동 중이나 모임 중처럼 확인이 어려운 상황에서 반복한다.

라스트레인은 그 계산을 대신해 세 가지를 보여준다.

1. 지금 나가면 탈 수 있는가
2. **최종 출발 마감시각** — 기존 앱이 제공하지 않는 숫자
3. 끊기는 구간과 그 원인

## 핵심 로직 — 역산 (backward induction)

도착지에서 거꾸로 올라오며 각 구간을 "늦어도 몇 시에 시작해야 하는가"로 환산한다.
맨 앞까지 오면 그것이 최종 출발 마감시각이다.

어떤 구간의 역산 시각이 그 구간 막차보다 이르면, 뒤쪽 구간이 먼저 끊긴다는 뜻이다.
그 구간을 **병목(끊기는 구간)** 으로 표시하고 원인이 되는 뒤쪽 구간을 함께 보여준다.

규칙 기반이라 결과가 재현되고, 판정 근거를 화면에서 그대로 펼쳐 볼 수 있다.

## 개인 보행 템포

도보 시간에 개인 배율을 적용한다. 10/3 사용자 인터뷰에서 나온 문제다.

> "발목 깁스한 상태인데, 내 이동시간과 지도 앱에 나온 도보 소요 시간이 차이가 많이 나서 막차를 놓쳤다."

배율을 바꾸면 마감시각이 움직이고, 빠듯한 경로에서는 판정 자체가 뒤집힌다.

## 데이터

| 항목 | 출처 | 상태 |
|---|---|---|
| 경로 11개 · 구간 소요시간 · 도보시간 | 조원 사용자 조사 (지도 앱 실측 캡처) | 확보 |
| 막차 시각 — 평일 | 조원 사용자 조사 | 11개 경로 확보 (버스 2구간 제외) |
| 막차 시각 — 토·일 | 조원 사용자 조사 | R01~R06만 확보 |
| 버스 시간표 vs 실제 운행 | 카카오맵 시간표·예측 대조 5건 | 격차 −10~+92분, 보정 안 함 |

원본은 `data/routes.json`.

## 구조

단일 HTML 파일. 빌드 도구 · 프레임워크 · 백엔드 없음.

```
index.html         전체 (스타일 · 판정 로직 · 경로 데이터)
data/routes.json   조원 조사 원본
```

API를 화면에서 실시간 호출하지 않고 수집해 둔 응답을 고정으로 사용한다.
데모 중 네트워크 실패로 판정이 멈추는 것을 막기 위한 선택이다.

### v0.7 — 2026.10.24
- 출발지·도착지를 짝으로: 출발지를 고르면 도착지가, 도착지를 고르면 출발지가 자동으로 채워짐 (카카오맵식 목록)
- 시연 컨트롤 창 삭제 → 결과 상단 바에 빨리 감기 버튼만. 시각은 홈의 출발 시각으로 정함

### v0.6 — 2026.10.24 (레퍼런스: 셔클 출발/도착 카드)
- 흐름을 홈 → 로딩 → 결과 3단으로. 홈에서 도착지·출발 날짜/시간·걸음 속도를 다 고른 뒤 "막차 확인"
- 요일 탭 삭제 → 실제 날짜(오늘~7일 뒤) + 시간(지금/지정) 시트. 고른 날짜가 어느 막차 시각(평일 / 토·일)으로 판정되는지 명시
- 로딩 1.4초: 달리는 아바타 + 사용 팁 (걸음 속도, 마감을 정하는 구간, 버스 점선)
- 결과 화면 상단에 판정 조건 요약 + 뒤로 가기

### v0.5 — 2026.10.24 (레퍼런스: LibMatch 검색행 + 렌터카 앱 검색 바·조건 칩·바텀시트)
- 진입을 "어디로 가세요?" 검색으로. 도착지를 입력하면 조사된 11개 경로에서 찾고, 없으면 "아직 막차 데이터가 없어요"
- 출발지 설정 시트: 현재 위치는 미지원이라고 명시(실시간 경로 API 필요), 조원 실측 출발지에서 선택
- 선택 후 상단 검색 바 + 조건 칩(요일 · 걸음) → 바텀시트에서 변경
- 의미색 재정의: 민트 = 탈 수 있음, 잉크(검정) = 끊김, 점선 회색 = 모름. 빨강·노랑은 노선색에만

### v0.4 — 2026.10.24 (`/impeccable critique` 2차 26/40 반영)
- 긴박도 단계: 10분 이하 테두리 강조 → 5분 이하 진한 민트 반전 → 1분 이하 강조 1회
- 1시간 넘게 남으면 마감시각, 1시간 이내면 분·초 카운트다운
- 마감을 넘기면 "지금 나가면 정자역에서 끊겨요". 이미 지난 시각은 취소선
- 걸음 속도 효과 표시: "보통 걸음보다 6분 일찍", 도보 행 "지도 앱 5분 → 내 걸음 9분"

- 포커스 링 복구, 스크린리더가 경로·요일·걸음 변경 때마다 새로 읽음, h1 추가

### v0.3 — 2026.10.24 (`/impeccable critique` 25/40 반영)
- 판정을 첫 화면 맨 위로. 경로·요일·걸음 속도는 한 줄 요약으로 접음
- 큰 숫자를 "출발까지 남은 시간 N분 NN초"로. 마감시각(분 단위)은 보조로
- 실시간 시계가 기본. 시각 지정·빨리 감기는 접히는 "시연 컨트롤"로 분리

- 마감을 넘기면 "지금 나가면 여기까지는 갈 수 있어요"(예: 정자역) 표시
- 빨강은 실제로 끊길 때만. 마감을 정하는 구간은 중립색 + "마감 결정" 라벨
