왜 이 시각인가요

도착지에서 거꾸로 올라오며 각 구간을 “늦어도 몇 시에 시작해야 하는가”로 바꿉니다. 맨 앞까지 오면 그게 최종 출발 마감시각입니다.

놓쳤을 때

이 화면의 숫자에 대해. 경로와 구간 소요시간은 ODsay 대중교통 API 실제 응답에서 가져왔고, 막차 시각은 아직 실측 전 샘플값입니다. 들어있는 경로 4개도 동작을 보여주기 위한 예시라, 실제로 어떤 귀가 경로가 대표성을 갖는지는 사용자 조사로 정해야 합니다.
